梦角频率

回你消息的频率
不是每次必回时，梦角有时会只留一个「已读」，不接话。
回复前的间隔
大约等 秒后回复
你发完消息后，梦角"打字"的时间。很快 0.2～0.5 秒，正常 0.6～1.4 秒，慢一些 1.6～3.2 秒。
回复时用表情的频率
梦角会从「黄脸 / 颜文字 / 表情包」里随机挑一个回给你——包括内置的和你自己添加的。
梦角主动拍你的频率
梦角会毫无理由地拍你一下，聊天里显示成「梦角 拍了拍你…」。 设成「关闭」它就不会主动拍你，但你双击它头像时它仍然会回拍你。
按当前时段优先抽卡
开启后，梦角会看时间挑卡：清晨偏向早晨 / 问候， 白天偏向日常 / 闲聊 / 食物 / 关心， 傍晚偏向加班 / 计划 / 旅行， 深夜偏向深夜 / 睡前 / 晚安 / 心情。约 3/4 的概率优先，其余纯随机。
主动打给你的频率
最短 分钟
最长 分钟
网站开着时梦角可能主动来电。预设：很少约 15～30 分钟，偶尔约 5～12 分钟，经常约 1.5～4 分钟； 自定义时，实际间隔会在你填的「最短～最长」之间随机取。

导出备份

自动备份到文件 未开启

选定一个文件后，之后每次改动都会自动写进去（每 5 秒最多一次），不用再手动导出。 把文件放在坚果云 / OneDrive / Dropbox 的同步目录里，手机装个客户端就能拿到最新备份。

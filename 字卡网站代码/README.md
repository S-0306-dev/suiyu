# 字卡传讯 · 与梦角对话

一个**一对一字卡传讯**网站：你给「梦角」发消息，梦角从你自己编辑的**字卡库**里**随机抽一张卡**作为回复。
整体为淡紫色系，纯前端实现，双击即可使用，数据全部保存在你自己的浏览器里。

---

## 一、怎么打开

直接双击 `index.html`，用 Chrome / Edge 等浏览器打开即可，**不需要安装任何环境**。

> 首次打开会自带 398 张示例字卡，你可以随意修改或清空。
> 如果你**已经打开过网站**，`js/data.js` 的改动不会自动生效；
> 这时在**字卡库 →「导入文件」**里把补充包文件选进来即可（也可以一起全选，一次导入）：
> `字卡补充包-日常交流.txt`（46 张）、`字卡补充包-情侣对话.txt`（60 张）、
> `字卡补充包-情侣关系.txt`（56 张）、`字卡补充包-情侣场景.txt`（84 张）、
> `字卡补充包-情侣场景2.txt`（74 张）、`字卡补充包-关系阶段.txt`（48 张）。

### 手机上怎么用

把整个文件夹传到手机（微信 / QQ 传文件、网盘、数据线都可以），用浏览器打开 `index.html`。
界面是自适应的，**功能与电脑端完全一致**：

- 字卡库不再固定在左侧，改为**独立页面**：主页点「字卡库」进入，页面左上角 `‹` 返回。
- 卡片的**编辑 / 删除**、消息上的**换一张 / 复制**、自定义表情的**删除**，
  在触摸设备上会**常驻显示**（不会因为"没有悬停"而点不到），并且按钮已放大到适合手指的尺寸。
- 输入框字号强制 16px，避免 **iOS 聚焦时自动放大页面**。
- 已适配**刘海屏 / 灵动岛 / 底部指示条**（safe-area），顶栏和输入框不会被压住。
- 顶栏按钮一个不少；卡池数量从胶囊挪到名字下面的状态行，极窄屏只显示数字。
- 减弱了大面积背景模糊，手机滚动更顺。

> 手机上推荐用 **Chrome** 或 **Edge**（Safari 对本地 HTML 限制较多）。
> 可以在浏览器菜单里选「添加到主屏幕」，之后会以独立窗口全屏打开，更像一个 App。

### 主页（手机主屏）
打开网站先看到的是一个「手机主屏」样子的主页：

- 顶部是实时**时钟与日期**，下面是梦角的头像和一句**随时段变化**的问候
- 中间是**应用图标网格**，分两页，底部有**页码点**；手机上左右滑动翻页，电脑上点页码点或按 `←` `→`

**第 1 页（常用）**

| --- | --- |

| 表情 | 进入聊天并打开表情面板 |
| 通话 | 进入聊天并打开拨号菜单 |
| 梦角 | 打开梦角资料 |
| 频率 | 打开梦角频率 |
| 备份 | 打开备份与恢复 |

**第 2 页（工具）**

| 图标 | 作用 |
| --- | --- |
| 拍一拍 | 直接拍一下梦角（等同双击它的头像） |
| 批量导入 | 批量粘贴导入字卡 |
| 导入备份 | 选文件导入备份 |
| 清空对话 | 清空聊天记录（带确认） |

| 关于 | 看一眼当前的数据统计 |

#### 排序与收起
**长按任意图标**（电脑上也可以右键）进入编辑模式：所有图标开始抖动，每个左上角出现 `×`。

- **拖动图标**可以调整顺序，顺序会记住
- 点 `×` 可以把不用的图标**从主页收起来**，点右上角「恢复隐藏」一次全部还原
- 点「完成」退出编辑模式

#### 纪念日组件
主页上是一份**纪念日清单**，一行一个，主页上最多同时显示 3 条（更多的话标题旁边会写「共 N 个」）。
一条都没加时，显示一行虚线提示「点这里添加一个纪念日」。

每行有三块内容：

| 位置 | 含义 |
| --- | --- |
| **名称** | 你给这个日子起的名字（前面带 💜，勾了「每年重复」的生日类会显示 🎂） |
| **副标题** | 第几个 · 还有多少天 |
| **右侧数字** | 从那天到今天一共过了多少天 |

几种特殊情况：

- 日期在过去：右侧显示 `已经 493 天`
- 日期还没到：右侧显示 `还有 39 天`，副标题写 `还有 39 天开始`
- **今天正好是那天**：整行会亮起来，图标变成 🎉，副标题写 `第 2 个 · 就是今天 🎉`
- 今天才开始（0 天）：右侧不显示数字

举例（今天是 2026-10-12）：

```
纪念日  共 3 个                                 ＋
┌──────────────────────────────────────────────┐
│ 💜  在一起                        已经 493 天 │
│     第 2 个 · 还有 237 天                     │
├──────────────────────────────────────────────┤
│ 🎂  梦角生日                      已经 9660 天│
│     第 27 个 · 还有 201 天                    │
├──────────────────────────────────────────────┤
│ 💜  第一次见面                     还有 39 天 │
│     还有 39 天开始                            │
└──────────────────────────────────────────────┘
```

点标题右侧的 **＋** 可以添加；**点任意一行会把那一条直接载入编辑**。点开弹窗后：

- 每条右侧有 **✎ 编辑** 和 **🗑 删除**
- 点 ✎ 会把那条载入下方表单（标题变成「编辑「…」」、按钮变成「保存修改」），改完点保存**就地更新**，不会新增一条
- 编辑到一半可以点「取消编辑」放弃
- 名称或日期为空时会拦下来并提示，不会默默失败
- 在名称或日期输入框里按 **回车** 也能直接提交

纪念日会随「完整备份」一起走，换设备不会丢。

#### 写信与信箱
聊天之外还有一个更"慢"的联系方式。

**写信**（主页第 2 页的 ✎ 图标，或信箱里的「写一封」）：

- 可以填一个**标题**（选填），正文想写多长都行，右下角会实时显示字数
- 可以选择**信纸**（5 款，见下），这个选择是全局的，所有信件都用同一张纸
- 点「寄出」后，梦角**先"读"一会儿**：聊天里会出现 `梦角正在读你的信` 的气泡，
  信箱里也会有一条跳动的占位行。约 4～6 秒后才回信
- 在正文框里按 `Ctrl/Cmd + Enter` 也能直接寄出

**梦角的回信**长这样：

```
你写：「今天把阳台的花浇了」        ← 引用你信里的原话

这句话我看了好几遍。                ← 一句回应

距你上次写信，已经 6 天了。          ← 距上一封信的间隔（超过 1 天才出现）

{字卡 1}

{字卡 2}

{字卡 3}
```

- 它会把你的信**按句切开，挑一句引用**（4～40 字的句子优先），再配一句回应
- **还会算你两封信之间隔了多久**，隔了 1 天以上就写进信里：
  `距你上次写信，已经 6 天了。` / `上一封信是 6 天前收到的，我数着呢。` / `你上一次动笔，是 6 天前的事。`
- 正文再从字卡库随机挑 **2～4 张**串起来
- 如果你的信太短、挑不出可引用的句子（比如只写「想你。」），就退回到一句普通的开头：
  `见字如面。` / `展信佳。` / `收到你的信了。` / `我慢慢回你，别急。` / `读完了，想了很久才回。`

**信纸款式（每封信各自记住）**

| 款式 | 说明 |
| --- | --- |
| **素纸**（默认） | 米色，经典信纸 |
| **横线纸** | 米色 + 淡紫横线 |
| **牛皮纸** | 暖褐，配深棕墨色 |
| **樱纸** | 淡粉，配梅色墨色 |
| **夜纸** | 深紫底 + 浅色字 |

- 在**写信**窗口选信纸 = 设定"以后新写的信用哪张"，这一封也会用它
- 读信界面下方也有一排信纸，**改了只影响这一封** —— 每封信各自记住自己用的纸
- 切换信纸时，纸面、字色、落款色、左侧竖线颜色都会一起变

**导出单封信**

读信界面右下角有两个按钮：

- **导出文字** → 下载一个 `.txt`，包含标题、日期、正文、落款
- **导出图片** → 用 Canvas 把信**画成一张 760px 宽的 PNG**（纸面、横线、竖线、标题、断行、落款全都渲染进去），不依赖任何第三方库

文件名形如 `信件-梦角回信-一封回信-20261012.png`。

**信箱**：

- 按时间倒序列出所有信件，未读的会高亮并显示一个小圆点
- 点开是**信纸样式**的阅读界面：米色纸面、左侧一道红色竖线分隔、衬线字体、右下角落款
- 主页「信箱」图标上会显示**未读数角标**，读完自动清零
- 底部可以**删除这封**
- 「**让梦角写给我**」按钮可以让它主动写一封；它有 6 成概率动笔，否则会在聊天里给你一句推托

信件和信纸设置都会随「完整备份」一起走。

#### 朋友圈
主页第 2 页的 📷 图标会打开**独立的朋友圈页面**（不是弹窗）：

- 电脑上是一块 **460×852 的手机面板**居中显示，手机上铺满全屏
- 页面顶部有自己的**标题栏 + 返回按钮**，右上角显示条数
- 点左上角 `‹`、按 `Esc`、或者从别处回主页，都会回到主屏
- 页面主体自己滚动，长列表不会撑破布局

**发动态**：

- 顶部写一句话，也可以点「加图片」附照片，**一次最多 9 张**
- 图片会**自动压缩**到最长边 640px、JPEG 质量 0.68，再以 data URL 存进数据里 ——
  所以它能跟着「完整备份」一起走，换设备照片不会丢
- 加了图之后，草稿区会显示**缩略图九宫格**，每张右上角有 `×` 可以单独移除，末尾还有一个 `＋` 继续加
- 单张超过 220KB 会跳过并提示；`Ctrl/Cmd + Enter` 也能直接发表

**九宫格排版**：1 张是大图，2 张两列，3 张三列，4 张 **2×2**，5～9 张三列 —— 和微信一致。

**图片可以左右翻看**：点任意一张进入全屏，多张时左右有 `‹ ›` 按钮、底部显示 `2 / 4`，
键盘 `←` `→` 也能翻，点空白处或按 `Esc` 关闭。

**保存单张图片**（两种方式）：

- 全屏时点右下角「**保存图片**」，会下载当前正在看的那一张
- **长按**（手机）或**右键**（电脑）九宫格里的任意一张，直接保存那一张

文件名形如 `朋友圈-20261012-1.jpg`。

**筛选：「全部 / 我 / 梦角」** 动态列表上方有一排筛选按钮，可以只看自己的或只看梦角的，
条数会显示成「共 3 条 · 筛选出 1 条」。

**按时间轴分组**：动态会按 **今天 / 昨天 / 本周 / 今年内的月份 / 年份** 分段显示，每段前面有小标题和分隔线。

**梦角会互动**：你发完约 2～4 秒后，它**点个赞**，再用一张字卡当**评论**。

**@ 梦角**：正文里写 `@梦角`（或 `@` 后面跟它的名字），它会：

- 在正文里被**高亮**成一个小标签
- **必定回应**（不是 55% 概率），而且明显更快（约 1～2 秒）
- 评论会先应一声：`叫我了？` / `诶，在的。` / `嗯？怎么啦。` / `你这样叫我，我马上就来了。`，再接字卡内容

**评论还能继续聊**：你在任意动态下评论后，梦角有约 **55%** 的概率**回复你的评论**（显示成
「梦角：回复 我 ……」），评论里写 `@` 同样会触发必定回复。

**你也可以互动**：

- 点 🤍 赞 / ❤️ 已赞 给自己或梦角的动态点赞，点赞者名单显示在右侧
- 每条动态下面都有评论输入框，回车或点「评论」发送
- 每条都能删除（带确认）

**让梦角发一条**：6 成概率它会发一条（内容取自字卡库），否则跟你说一句"没什么想发的"。
梦角发的动态会在主页图标上显示**未读角标**，打开朋友圈就清零。

> 关于「梦角也给别人的动态点赞」：这个应用里只有梦角一个角色，没有"别人"。
> 所以我把它做成了**梦角回复你的评论** —— 如果你以后想要多个角色，我再加。

> 图片是直接存在数据里的，朋友圈多了以后会占用浏览器存储。
> 如果写入失败，会提示「存储空间不足」，删掉几条带图动态即可。

#### 壁纸
主页壁纸有 **6 套内置配色**（淡紫 / 星夜 / 樱花 / 薄荷 / 暮色 / 极光），也可以**上传自己的图片**
（小于 5MB，存在浏览器里，刷新后依然在）。深色壁纸下时钟和文字会自动变成浅色。

#### 其它
- 聊天栏左上角的 **🏠** 按钮随时可以回到主页
- 角标只用在「**有未读**」的场景：「信箱」显示未读信数、「朋友圈」显示梦角的新动态数。
  字卡数量这类固定信息不放在图标上，进「字卡库」页面就能在标题栏看到（例如 `398 张`）。
- 电脑上主页会呈现成一块 **430×852 的手机面板**居中显示，手机上则铺满全屏
- 在主页时梦角打电话过来，通话界面会正常盖在上面

> 主页只是入口，所有功能都在同一个页面里，不会多开窗口；回到主页时会自动关掉打开的弹窗和抽屉。

## 三、功能一览

### 聊天
- 输入消息发送后，梦角那侧会先冒出一个「**正在输入中**」的气泡（带三个跳动的小点），
  停顿一下之后才抽一张卡回给你。停顿多久可以在「梦角频率 → 回复前的间隔」里调。
- **双击梦角的头像**可以拍拍它，详见下面的「拍一拍」。
- 每条梦角回复下方有两个快捷按钮：
  - **换一张**：对这条消息重新随机抽一张卡。
  - **复制**：复制该字卡内容。
- 顶部显示当前**卡池数量**、梦角名字与状态。
- 右上角可**清空对话**（不影响字卡库）。

### 表情（黄脸 / 颜文字 / 表情包）
输入框左边的笑脸按钮打开表情面板。面板分**三个互相独立的页**，点哪个页就只看得到那一类：

| 分页 | 内置内容 | 点击后 |
| --- | --- | --- |
| **黄脸** | 147 个 emoji（笑脸、手势、爱心、装饰） | 插入到输入框光标处 |
| **颜文字** | 64 个颜文字，如 `(＾▽＾)`、`(๑•̀ㅂ•́)و✧`、`ʕ•ᴥ•ʔ` | 插入到输入框光标处 |
| **表情包** | 16 个内置表情（纯 SVG 现画） | 直接作为一条消息发出去 |

每一页内部又分成「内置」和「我添加的 / 我导入的」两块，**都可以持续往里加东西**：

- **黄脸**：在底部输入框粘贴 emoji 后点「添加」。一次可以粘一串（如 `😺🐰🦊`），
  会按字素自动拆成 3 个分别加进去。
- **颜文字**：同样在底部输入框里输入或粘贴，整条作为一个颜文字加入。
- **表情包**：点「导入图片」选本地图片（PNG / JPG / GIF，单个小于 2MB，可多选）。

自己加的内容都会记住：

- 黄脸和颜文字存在 localStorage，会随**导出 JSON** 一起带走；
- 表情包图片存在 IndexedDB，不随 JSON 导出，换设备需要重新导入。

鼠标悬停在「我添加的」条目上，点右上角的 `×` 就能删除。

其它：

- 内置表情包是**代码里现画的 SVG**（微笑 / 开心 / 害羞 / 喜欢 / 星星眼 / 闪闪 / 眨眼 / 哭了 / 难过 /
  生气 / 惊讶 / 困了 / 思考 / 累瘫 / 猫猫 / 比心），**不需要任何图片文件**。
- 发出表情包同样会触发梦角抽卡回应。

### 梦角频率（回复 / 间隔 / 表情 / 拍一拍 / 时段 / 来电）
点聊天栏右上角的**滑块图标**打开「梦角频率」，六个旋钮都能调，底部还有「恢复默认」。

**1. 回你消息的频率**

| 选项 | 回复概率 |
| --- | --- |
| 很少 | 25% |
| 一半 | 50% |
| 经常 | 85% |
| 每次必回（默认） | 100% |

不是每次必回时，梦角有时只会留一个小小的「已读」，不接话。

**2. 回复前的间隔（梦角「打字」的时间）**

| 选项 | 间隔 |
| --- | --- |
| 很快 | 0.2～0.5 秒 |
| 正常（默认） | 0.6～1.4 秒 |
| 慢一些 | 1.6～3.2 秒 |
| **自定义** | 填一个秒数（0.1～10），实际在 ±35% 内随机浮动 |

**3. 回复时用表情的频率**

| 选项 | 非字卡回复的比例 |
| --- | --- |
| 关闭 | 0%（只用字卡） |
| 偶尔（默认） | 约 18% |
| 经常 | 约 35% |
| 一半一半 | 约 50% |

轮到表情时，再从 **黄脸 / 颜文字 / 表情包** 三类里按权重随机挑一类（约 40% / 38% / 22%），
最后从该类里随机取一个。

**4. 梦角主动拍你的频率**

| 选项 | 每次回复被拍的概率 |
| --- | --- |
| 关闭 | 0% |
| 偶尔（默认） | 约 8% |
| 经常 | 约 18% |
| 一半一半 | 约 35% |

梦角会毫无理由地拍你一下，聊天里显示成 `👉 梦角 拍了拍你…`。这一项**和表情频率相互独立**
——两项都设成「关闭」，它就会老老实实只抽字卡。

> 「关闭」只影响它**主动**拍你；你双击它的头像时，它仍然有一半概率回拍你。

**5. 按当前时段优先抽卡**

| 时段 | 偏向的标签 |
| --- | --- |
| 05:00 ～ 11:00 | 早晨 / 问候 |
| 11:00 ～ 18:00 | 日常 / 闲聊 / 食物 / 天气 / 关心 / 反问 / 状态 |
| 18:00 ～ 23:00 | 问候 / 加班 / 计划 / 旅行 / 和解 / 心情 |
| 23:00 ～ 05:00 | 深夜 / 睡前 / 晚安 / 思念 / 心情 / 感叹 |

开启（默认）时，约 **3/4** 概率从当前时段的标签里抽卡，剩下 1/4 仍然纯随机；
关闭则完全纯随机。**通话时梦角「说」的字卡也走同一套规则** —— 所以深夜打给你时，
它更容易说「晚安，梦里见」而不是「中午好，吃饭了没有」。

**6. 主动打给你的频率**

| 选项 | 间隔 |
| --- | --- |
| 关闭 | 不主动来电 |
| 很少 | 约 15～30 分钟 |
| 偶尔（默认） | 约 5～12 分钟 |
| 经常 | 约 1.5～4 分钟 |
| **自定义** | 分别填「最短」和「最长」分钟数（0.5～720），实际间隔在你填的区间内随机取 |

这一项和通话菜单里的「允许梦角主动来电」开关是同一个设置，改哪个都会同步。

> 「回复前的间隔」的自定义带 ±35% 随机浮动，是为了避免梦角像定时任务一样每次都掐着点出现。
> 来电的「自定义」**不再额外浮动** —— 你填的最短～最长就是实际范围，想让节奏规律就填成一样。

---

关于表情回复的几个细节：

- 三类里都**包含你自己添加 / 导入的内容** —— 你之后新加的表情，梦角下一句就可能用上。
- 黄脸回复显示成一个大号表情（不带气泡背景），颜文字是普通气泡，表情包则是表情气泡。
- 每条回复下方的 **换一张** 依然有效，而且可以**跨类型重抽**（字卡 ↔ 表情 ↔ 表情包都行）。
- 字卡库为空时，梦角会全用表情回复；表情为空时，则回到纯字卡。

顺带一提：**黄脸和颜文字本身就是文字**，所以你完全可以把它们写进字卡里，
让梦角把它们当成「台词」来说。

### 通话（语音 / 视频）
点聊天栏右上角的电话图标，可以选择拨**语音通话**或**视频通话**：

- **语音通话**：梦角用字卡「说话」，界面上是**静音字幕**（不播放声音）。
- **视频通话**：画面为梦角头像 + 氛围动效（呼吸浮动、光晕、漂浮粒子），同样以字幕呈现字卡。

通话中的操作：

| 按钮 | 作用 |
| --- | --- |
| 切到视频 / 切到语音 | 通话途中随时切换通话类型 |
| 免提 | 切换「大字幕」模式：字幕放大、头像缩小，手机放桌上离远了也能看清 |
| 音乐 | 随时开关背景音乐 |
| 让梦角说 | 立刻让梦角再抽一张字卡说给你听 |
| 挂断 | 结束通话，并在聊天里留下通话记录 |

左上角徽章显示当前通话类型；右上角有一个语言小圆钮（`简 / 繁 / EN`），点一下就能轮换字幕语言。

### 字幕语言
拨号菜单里的「字幕语言」提供 **简体中文 / 繁體中文 / English** 三档，切换的是**通话界面的文字**
（按钮、状态、通话记录、系统提示）。字卡内容保持你写的原文不变（那是你自己的文字，程序不会改动它）。

设置会保存在本地，下次打开依然生效。

### 背景音乐
拨号菜单下方是「背景音乐」区域：

- **内置生成**：用 Web Audio 实时合成，**无需任何音频文件，离线也能响**。内置四种音色：
  - **氛围白噪音**（默认）：三层粉红噪声叠成——低频暖噪打底、中频身体、高频空气感。
    每层都有各自极慢的音量起伏，像呼吸一样缓缓流动，柔和、舒服、不带旋律。
  - **雨声**：在偏亮的雨幕底噪之上，另加一层**随机雨点颗粒**——每秒十来个极短的高频
    噪声脉冲，音高、长短、左右声像都随机，听着就是细碎的雨。
  - **风声**：起伏比白噪音**更慢更大**，并且给滤波器截止频率叠加了很慢的扫动，
    所以会有「一阵一阵」的强弱变化，像风穿过。
  - **柔和和声**：一套缓慢行进的和声垫底（Cmaj7 → Am7 → Fmaj7 → G6），
    加上偶尔飘出的、起音很软的铃声。
- **自己的文件**：点「选择音乐文件」挑一首本地音频（`mp3 / wav / m4a` 等，小于 25MB），循环播放。
  文件会存进浏览器的 IndexedDB，**刷新后依然记得**，点「清除」可以移除。
- **音量**：拖动滑杆实时调整。

**通话音效**（和内置音乐同一套合成方式，不需要任何音频文件）：

- 拨出时的**回铃音**：一次很轻的「呼吸」声，约每 4.4 秒一次，没有尖锐的起音。
- 梦角来电时的**铃声**：两声交叠的柔和呼吸，约每 5.4 秒一次，中间留出安静的间隙。

> 所有音效都刻意做成了**慢起音 + 长释放**，不会有"叮"的一声，安静环境下戴耳机也不会觉得刺耳。

> 因为浏览器不允许页面在用户操作之前自动播放声音，请先点击过页面任意位置，音乐与铃声才会响。

其它说明：

- 接通后梦角每隔几秒自动抽一张字卡「说」一句，字幕显示在屏幕下方。
- 结束后聊天里会出现一条记录，例如「📞 语音通话 · 通话时长 01:24 · 梦角说了 9 句」。
- **梦角主动来电**：默认开启。网站开着时梦角可能随机打给你，并由它决定打语音还是视频；
  在同一个菜单里取消勾选「允许梦角主动来电」即可关闭，来电间隔可以在**「梦角频率」**里调整。
- **让梦角打给我**：点这个按钮后，由梦角决定要不要打来、打语音还是视频——它也可能拒绝你，并留一句话。
- 拒绝来电时，梦角会回你一句，同时留下一条「已拒绝」的记录。

### 页面导航
主页的图标分成两类：

- **打开独立页面** —— 字卡库 / 写信 / 信箱 / 朋友圈，左上角都有 `‹` 返回按钮
- **直接操作** —— 传讯（进入聊天）、新建字卡、表情、通话、梦角、频率、备份、拍一拍 等

页面规则：

- 同一时刻**只有一个页面可见**（主页 / 聊天 / 四个子页面），互不重叠
- 点页面左上角 `‹`、按 `Esc`，都会回到主页
- 电脑上子页面都是 **460×852 的手机面板**居中显示（主页是 430×852），手机上铺满全屏
- 页面主体自己滚动，长内容不会撑破布局
- 从信箱点「写一封」会直接切到写信页面，不会来回弹窗

> 聊天页现在没有侧栏了 —— 需要看字卡库就从主页进。桌面上聊天窗口因此收窄到 880px，阅读更集中。

### 字卡库（独立页面）
- **新增字卡**：可视化编辑器，填写「内容 + 标签（可有多个）」。
- **双击卡片**可快速编辑；悬停卡片显示编辑 / 删除按钮。
- **搜索**：按内容或任意标签实时筛选。
- **列表 / 分组**：右上角可切换视图，见下。
- **批量导入**：一次粘贴多行文字（**自动去重**）。
- **导入文件**：直接从 `.txt` / `.json` 文件导入字卡，**可以一次选多个文件**（**自动去重**，见第四节）。
- **导入 / 导出 JSON**：方便备份与迁移。
- **清理重复**：页面底部，内容完全一样的卡只留一张，其它卡上的标签会合并过来（带二次确认）。
- **清空字卡库**：带二次确认。

#### 字卡分组（多标签）
每张字卡可以有**多个标签**，分组就是**按标签归类**。在字卡库页面的搜索框下面有一排切换：

- **列表**：原样平铺，适合作业时逐张翻看
- **分组**：按标签分成若干段，每段是**可点击折叠的标题栏**，显示标签名和张数
- 一张卡有多个标签时，会**同时出现在多个分组里**
- 分组按**张数从多到少**排列，**「无标签」永远排最后**
- 右下的「**全部收起 / 全部展开**」一键控制所有分组
- **搜索时会自动强制展开**，免得命中的卡片被折叠藏起来；清空搜索后恢复你原来的折叠状态
- 视图选择和每个分组的折叠状态都会**记住**，下次打开还是这样

**编辑标签**：新增 / 编辑字卡时，标签是个 **chip 输入框** —— 输入后按回车（或逗号）就变成一个标签胶囊，
按 `Backspace` 删掉最后一个，每个胶囊上的 `×` 单独移除。一张卡最多 8 个标签。

三个组织动作：

| 动作 | 怎么做 |
| --- | --- |
| **换组** | 在分组视图里**把卡片拖到另一个分组**，就给它加上那一组的标签；拖到「无标签」组 = 清空这张卡的标签 |
| **重命名** | 悬停分组标题栏，点右侧的 **✎**，输入新名字即可；这一组下所有卡片的该标签会一起改 |
| **合并** | 重命名时如果输入的名字已存在，会先问你要不要合并过去 |

> 拖动时**拖到列表上下边缘会自动滚动**，所以能拖到屏幕外的分组。
> 另外，拖到已经属于的分组会提示「这张卡已经在这一组里了」，普通点击不会误触发拖放。

> 折叠起来的分组不会渲染里面的卡片，所以字卡很多时切到分组视图滚动会明显更轻快。

### 梦角资料
点资料卡右侧的铅笔按钮，可修改**名字**、**签名/状态**、**拍一拍后缀**和**头像**
（内置表情可选，也支持上传本地图片）。

### 拍一拍
**双击梦角的头像**（顶栏那个，或者侧栏梦角资料卡上的那个），就能拍它一下：

- 头像会晃一下，聊天里出现一行小字：`👉 你拍了拍「梦角」的肩膀`
- 之后梦角**有一半概率立刻回拍你**（输入框会晃一下），另一半概率抽一张字卡回你
- 梦角也会**自己主动拍你** —— 频率在「梦角频率 → **梦角主动拍你的频率**」里单独调（与表情频率相互独立）
- **拍一拍后缀**可以在「编辑梦角资料」里改，两个方向共用同一个后缀，
  比如改成「的头发，把它揉乱了」，就会变成 `👉 你拍了拍「梦角」的头发，把它揉乱了`
- 有 0.9 秒冷却，手快连点不会刷屏

> 用「点击两次」而不是原生双击事件来判定，所以鼠标双击和手机双击都能触发。

## 四、字卡导入格式

> **自动去重**：「批量导入」和「导入文件」两条路都会自动去重 —— 内容完全一样的卡**不会重复进库**。
> 批内重复（同一批里出现两次）和与库内已有的重复都会被跳过，导入前后都会告诉你跳过了几张。
> 如果库里**本来就有**重复，底部的「清理重复」可以把它们合并掉（见第三节）。

### 批量导入（文本）
一行一张卡，支持三种写法：

| 写法 | 说明 |
| --- | --- |
| `标签 \| 字卡内容` | 用竖线分隔标签和内容 |
| `【标签】字卡内容` | 用方括号写标签 |
| `字卡内容` | 不带标签 |

以 `#` 或 `//` 开头的行会被当作注释忽略。示例：

```
晚安 | 闭上眼睛之前，记得把眉头松开。
鼓励 | 你已经做得很好了，比你以为的要好得多。
【思念】你不说话的时候，我会偷偷想你。
今天也想见你。
# 这行是注释，会被忽略
```

### 导入 JSON
兼容以下三种结构，导入时**追加**到现有字卡库：

```json
// 1. 本站导出的完整文件
{ "format": "dream-card-chat", "version": 1, "cards": [ { "tag": "晚安", "text": "早点儿睡。" } ] }

// 2. 纯数组
[ "今天也想见你。", { "tag": "鼓励", "text": "慢慢来。" } ]

// 3. 单个对象
{ "tag": "思念", "text": "距离对梦来说不算数。" }
```

### 从文件导入（字卡库 →「导入文件」）
字卡库页面第二排有一个 **导入文件** 按钮，选好文件就直接读进来，**支持一次选多个文件**。

| 文件 | 怎么解析 |
| --- | --- |
| `.txt` / `.md` / `.csv` | 和「批量导入」同一套规矩：一行一张，`标签 \| 内容`、`【标签】内容`，`#` / `//` 注释会被忽略 |
| `.json` | 按下面的「导入 JSON」三种结构解析 |

几个细节：

- **自动认编码**：先按 UTF-8 读，读出乱码就自动换 GBK 再读一遍 —— Windows 记事本存的 txt 大多是 GBK，直接选就行，不用先转码
- **自动去重**：内容完全一样的卡不会重复进库，导入前会告诉你有几张会被跳过
- **只增不删**：往库里追加，已有字卡不受影响；读进来后会弹确认框，告诉你这次能加几张
- **失败不影响其它文件**：某个文件读不了（比如选了个不是字卡文件的 `.json`）会单独提示，其余文件照常导入
- 怎么判断是不是 JSON：文件名以 `.json` 结尾，或者内容以 `{` / `[` 开头

例：把 6 个「字卡补充包-*.txt」一起选中，一次就能全部并进字卡库。

## 五、数据存在哪里？怎么换设备？

所有内容都保存在**你自己的浏览器**里，不会上传到任何服务器：

| 内容 | 存放位置 |
| --- | --- |
| 字卡、聊天记录、设置、自己加的表情 | localStorage（键名 `dreamCardChat.v1`） |
| 导入的表情包图片、你选的背景音乐文件 | IndexedDB（`dreamCardChatMedia`） |

因此：更换浏览器、用无痕模式、清理浏览器数据之后，内容会丢。

### 让手机和电脑保持一致

**做法一：完整备份（推荐，一次搬完）**

1. 在「正确的版本」那台设备上，点侧栏 **导出备份 → 完整备份**，得到一个 JSON 文件。
   这个文件里装着**全部东西**：字卡、聊天记录、全部设置、自己添加的表情、
   导入的表情包图片、背景音乐。
2. 把这个文件传到另一台设备（微信 / QQ 传给自己、邮件、网盘都可以）。
3. 在另一台设备上点 **导入备份**，选中这个文件，确认「覆盖导入」。

导入是**覆盖式**的（不是追加），所以导完两台设备就完全一致了。

> 「只导出字卡库」是轻量版，只有字卡，适合分享给别人：对方拿到后在**字卡库 →「导入文件」**里选中它，会**追加**进自己的字卡库，不会覆盖。

**做法二：自动备份到文件（桌面端，省得反复导出）**

在 **导出备份 → 自动备份到文件 → 选择文件并开启**，选一个保存位置。
之后每次改动都会自动写进去（每 5 秒最多一次），**不用再手动点导出**。

把那个文件放在**坚果云 / OneDrive / Dropbox** 的同步目录里，手机装个客户端就能拿到最新备份，
在手机上「导入备份」选它即可。

> 几点注意：
> - 完整备份是覆盖式的，导入前先想清楚哪台设备是"对的那份"。
> - 备份里含图片和音乐（base64 内嵌），所以文件可能几 MB 到几十 MB。
> - 浏览器不允许网页自己写文件，所以自动备份第一次必须由你点一下「选择文件并开启」；
>   重启浏览器后如果状态显示「需要重新授权」，点一下「立即备份一次」即可。
> - 自动备份用的是 File System Access API，目前只有桌面版 Chrome / Edge 支持；
>   手机端请用「完整备份」手动导入。

## 六、自定义默认字卡（可选）

如果你希望「清空浏览器数据后重新打开」时出现的是自己写好的字卡，
可以编辑 `js/data.js` 里的 `DEFAULT_CARDS` 与 `DEFAULT_PROFILE`。

## 七、主题配色

淡紫色系配色集中在 `css/style.css` 顶部的 `:root` 变量里，想调整风格只需改这几个值：

```css
--primary:      #9a7dd6;   /* 主色 */
--primary-2:    #b8a3ea;   /* 主色浅 */
--primary-soft: #ede6fb;   /* 主色极浅（标签背景） */
--bg:           #f6f3fd;   /* 页面背景 */
--text:         #4a4161;   /* 正文文字 */
```
